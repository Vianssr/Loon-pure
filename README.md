# IPPure for Loon

Check a node’s exit IP and its IPPure risk score from the Loon node list. IPPure scores IPv4 addresses from 0 to 100. Lower scores indicate lower risk.

Requires Loon 3.5.1 (build 983) or later.

## Installation

In Loon, open **Plugins**, tap **+**, paste the URL below, then save and enable the plugin.

```text
https://raw.githubusercontent.com/Vianssr/Loon-pure/main/IPPure.plugin
```

## Usage

With Loon connected and scripting enabled, long-press or right-click a node and select **IPPure**. The request goes through that node.
